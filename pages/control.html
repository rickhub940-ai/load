อัปโหลดหรือกด แก้ไข สคริปต์ที่มีอยู่ได้ตลอด — ตัวไฟล์สคริปต์เก็บไว้บน GitHub (scripts/<name>.lua สูงสุด 25 MB) ส่วน Supabase เก็บแค่ metadata ขนาดเล็ก (ชื่อแมพ, Place ID และโหมดคีย์)

ใส่เฉพาะโค้ดของแมพได้เลย — runtime ตรวจสอบและบันทึกสถิติก่อนรันให้อัตโนมัติ ไม่ต้องคัดลอก verification จาก main.lua; obfuscate ทั้งไฟล์ได้
